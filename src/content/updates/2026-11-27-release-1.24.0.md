## “Cliff”

The winning vote during Office Hours was for naming this release “Cliff” after the 40<sup>th</sup> highest peak in New York: Cliff Mountain. The mountain was originally reported to have had an elevation of 4,000 ft (1,219 m). Thats equivalent to 24 Niagara Falls (167 ft Horseshoe drop) stacked bottom to top. It is part of the "Marcy Group" range of mountains.

In 1953 a United States Geological Survey found Cliff and three other peaks to be lower than 4,000 ft, but the list has not been changed. The mountain is still within the High Peaks Wilderness Area of Adirondack State Park. No marked trail leads to its summit.

[Learn more about Cliff Mountain <nys-icon name="open_in_new"></nys-icon>](https://en.wikipedia.org/wiki/Cliff_Mountain_(New_York))

## `<nys-onthispage>` released

In-page navigation is needed for long pages. We've created a new menu for in-page navigation: `<nys-onthispage>`. The nav will sit in your layout, generate a navigable list of headings from your page, and is configurable to specific heading levels, navigation method, and even excluding specific headings from the list. Give it a try on the right side of our page here, (RTL users, it's on the left), it's in use now!

[Read the \<nys-onthispage\> documentation](/components/onthispage)

## MCP Server refinements and usage guide fixes

More and more engineers are using AI to generate UI for sites and applications. The New York State Design System MCP Server is the rails we provide to LLMs to follow our usage guidelines. It is the official MCP server for the NYS Design System.

This release adds the @nysds/styles utility classes to the MCP server. So whether you are laying out a new app with grid classes, or ordering columns with flexbox, the MCP server will guide the creation based off NYSDS standards.

[Read about how the NYS Design System is used to assemble, not quess, using the MCP Server](/about/updates/nysds-mcp-server/)
