## “Sawteeth” 🏔️

The winning vote during Office Hours was for naming this release “Sawteeth” after the 35<sup>th</sup> highest peak in New York: Sawteeth Mountain. The Mountain has an elevation of 4,100 ft (1,200 m). That is as tall as 707 NYC Yellow Cabs stacked roof to roof! 🚕

[Learn more about Sawteeth Mountain <nys-icon name="open_in_new"></nys-icon>](https://en.wikipedia.org/wiki/Sawteeth_(New_York))

## Official Angular support

We've added official Angular support to the NYS Design System. Installation is as easy as an npm install and referencing the components in your source code. We've provided documentation for both quick start and detailed implementation patterns. Send us any comments in the Angular channel on Teams!

[Read the NYS Design System Angular support docs](/get-started/developers/angular/)

## Bug fixes

- MCP framework guides now reflect the correct method for installation and usage
- Vulnerabilities fixed
- CSS Private var cleanup
- Slight styling fixes for `<nys-verticalnav>`
- Fix `<nys-processlist>` showing full height in Safari
- Fix `<nys-breadcrumb>` to persist user provided classes
- Fix `<nys-datepicker>` focus trap and close calendar with a keystroke
- Fix `<nys-table sortable>` sorting numbers with commas

## 🚨 Breaking changes

- none
