## “Big Slide”

The winning vote during Office Hours was for naming this release “Big Slide” after the 27<sup>th</sup> highest peak in New York: Big Slide Mountain. The Mountain has an elevation of 4,240 ft (1,290 m). Thats equivalent to 8,480 Nathan’s hot dogs 🌭 stacked end to end. At Joey Chestnut’s record pace, that amounts to about 112 consecutive contests, or 19 hours of uninterrupted eating!

[Learn more about Big Slide Mountain <nys-icon name="open_in_new"></nys-icon>](https://en.wikipedia.org/wiki/Big_Slide_Mountain_(New_York))

## Improved Translation Support

In order to support upcoming localization efforts, we've added additional translation functionality to the `<nys-unavheader>`. The header now takes an optional property: `translateKey`. Provide a valid key to enable translation from our new localization platform. Any questions about Translation as a Service (TaaS) should be sent to [Translation@its.ny.gov](mailto:Translation@its.ny.gov) to get started.

[Read the `<nys-unavheader>` support docs](/components/unav-header/#translate-key)

## New `<nys-unavbundle>` Bundle

Most NYS websites feature our `<nys-unavheader>` and `<nys-unavfooter>` at the top and bottom of their pages. Since they are both used together, and you would never run one without the other, we've created our first "component bundle" named `nys-unavbundle`. Using the bundle is different from using a regular component, as it isn't a component itself, it simply bundles multiple components. So instead of inserting `<nys-unavbundle>` (Which doesn't exist), you would instead place the code for the header and footer as normal, but only load in the one nys-unavbundle javascript file.

More to come!
