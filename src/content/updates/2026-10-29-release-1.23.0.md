## “Big Slide” 🏔️

The winning vote during Office Hours was for naming this release “Big Slide” after the 27<sup>th</sup> highest peak in New York: Big Slide Mountain. The Mountain has an elevation of 4,240 ft (1,290 m). Thats equivalent to 8,480 Nathan’s hot dogs 🌭 stacked end to end. At Joey Chestnut’s record pace, that amounts to about 112 consecutive contests, or 19 hours of uninterrupted eating!

[Learn more about Big Slide Mountain <nys-icon name="open_in_new"></nys-icon>](https://en.wikipedia.org/wiki/Big_Slide_Mountain_(New_York))

## Improved Translation Support

In order to support upcoming localization efforts, we've added additional translation functionality to the `<nys-unavheader>`. The header now takes an optional property: `translateKey`. Provide a valid key to enable translation from our new localization platform. Any questions should be sent to [Translation@its.ny.gov](mailto:Translation@its.ny.gov) to get started.

[Read the `<nys-unavheader>` support docs](/components/unav-header/)

## Official React support

We've added official React support to the NYS Design System. Installation is as easy as an npm install and referencing the components in your source code. We've provided documentation for both quick start and detailed implementation patterns. Send us any comments in the React channel on Teams!

[Read the NYS Design System React support docs](/get-started/developers/react/)

## Bug fixes

- MCP framework guides now reflect the correct method for installation and usage
- Vulnerabilities fixed
- CSS Private var cleanup
- Slight styling fixes for `<nys-verticalnav>`
- Fix `<nys-processlist>` showing full height in Safari
- Fix `<nys-breadcrumb>` to persist user provided classes
- Fix `<nys-datepicker>` focus trap and close calendar with a keystroke
- Fix `<nys-table sortable>` sorting numbers with commas
