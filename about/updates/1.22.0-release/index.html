NYS Design System Release 1.22.0 “Sawteeth”

Added official support for Angular, React, and Vue. Setup instructions have been updated for each package and in our MCP server. Our new codegen package generates our framework-specific implementations from the source Typescript files. We also fixed a few bugs.

Eric Steinborn
October 2, 2026
2 min read time

“Sawteeth” 🏔️

The winning vote during Office Hours was for naming this release “Sawteeth” after the 35th highest peak in New York: Sawteeth Mountain. The Mountain has an elevation of 4,100 ft (1,200 m). That is as tall as 707 NYC Yellow Cabs stacked roof to roof! 🚕

Learn more about Sawteeth Mountain

Official Angular support

We've added official Angular support to the NYS Design System. Installation is as easy as an npm install and referencing the components in your source code. We've provided documentation for both quick start and detailed implementation patterns. Send us any comments in the Angular channel on Teams!

MCP server documentation updated

We added more details to the MCP server for each framework we support. Each framework features an in-depth installation and usage guide. Now your LLM will install and use the design system the way it's meant to.

Robert Chen verified all documentation!

Bug fixes

  • MCP framework guides now reflect the correct method for installation and usage
  • Vulnerabilities fixed
  • CSS Private var cleanup
  • Slight styling fixes for <nys-verticalnav>
  • Fix <nys-processlist> showing full height in Safari
  • Fix <nys-breadcrumb> to persist user provided classes
  • Fix <nys-datepicker> focus trap and close calendar with a keystroke
  • Fix <nys-table sortable> sorting numbers with commas

🚨 Breaking changes

  • none

⚠️ Known issues

  • nys-globalfooter does not allow you to dynamically insert menu items currently. See: Teams bug report
  • If you notice any issues, please add them to our GitHub Issue Tracker
